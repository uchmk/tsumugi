## Not ticked

- **`Ctrl+Shift+X`** (`swap_pane`) stays `[ ]`: **the key never reaches the app on Windows.** Pressed twice (also held):
  the key log has `ControlLeft` and `ShiftLeft` and **no `X` line at all**; the pane sizes, `ls --json` and the markers
  did not change. egui-winit turns Ctrl+X (any `command`+X, shift too) into `Event::Cut` (`is_cut_command` in its `lib.rs`) and
  never delivers `Key::X`, so `Key::X if ctrl_shift => SwapPane` (`keys.rs:522`) cannot fire; `main.rs` handles `Event::Copy`
  but not `Event::Cut`. The same goes for any binding set in `[keys]` to Ctrl+X or Ctrl+Shift+X.
- **`Alt+Shift+Down`**: outside the 20.

## Findings

1. **`Ctrl+Shift+X` is dead on Windows** (above). A user can still rebind `swap_pane`; the default does not work.
2. **`copy_output` takes the wrapped part of a long command line with the output** in pwsh. `Write-Output OUTLINE_A; Write-Output OUTLINE_B`
   in a 36-column pane gave the clipboard `put OUTLINE_A; Write-Output OUTLINE_B\nOUTLINE_A\nOUTLINE_B`: pwsh marks no
   OSC 133 `C`, so the code starts at "the row after the prompt" (`grid.rs`, `last_output`), which is the command's second
   row when it wraps. A short command is fine (`LINE1`).
3. **The status bar's pane size and branch overlap** with a narrow window/many panes (`C:\dev\tsumugi-wintest`, `pwsh · 36×28`
   and `test/win-keys-21` drew on top of each other in the bottom bar: see the bottom of `qs-on.png`, `tab9b.png`).
4. `tsumugi ls --json` has no `recording` field while recording (the app's `Info` has one); a script cannot ask whether a
   pane is being recorded. The cast file was what I read.
5. Once during `Ctrl+Alt+9` an `ArrowUp` (no modifiers) reached the shell 109 ms after typed text with no sender of mine
   (PTY log `\e[38;72;0;1;256;1_ (Up)`); not reproduced in the runs after it. Probably the kit's Alt release
   (the key log also shows `AltLeft` lines around chords) being seen as a key. Not chased.

### Proposals

- Handle `Event::Cut` in `main.rs` like Ctrl+X pressed with Shift (`SwapPane`) on Windows/Linux, or move the default away
  from Ctrl+X to a chord egui does deliver. Small: one match arm, plus a TESTING.md line to say the key works.
- For pwsh, have `shell-hook pwsh` mark the start of the output (OSC 133 `C`) from a PSReadLine `CommandValidationHandler`/
  `PSConsoleHostReadLine` wrapper, so `copy_output` and the margin bars do not need the "row after the prompt" guess. Medium.
- Put `recording` into `ls --json` so the row "the pane is recorded" can be read as text. Small.
- Move the status bar's folder / size / branch labels to ellipsize instead of overdrawing each other. Small.
