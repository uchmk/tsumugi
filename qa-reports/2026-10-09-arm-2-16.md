## Bugs

**Bug 1 — `Ctrl+Shift+-` sends nothing to the shell** (row 2.24).
`tsumugi-pane/src/input.rs` `key_bytes` → `printable('-')` → `control_code` (keys.rs ~:232, maps only ` `, `@`, letters, `[`, `\`, `]`, `^`, `_`, `?`) and
`char_record` (keys.rs ~:81, only A–Z and 0–9) both return `None` for `-`. No `in key` line appears in the PTY log, so readline's
undo (C-_) never arrives. `crates/tsumugi/src/keys.rs` ~:595 says the key "still sends" it.

**Bug 2 — copy mode** (rows 2.25, 2.26).
A char-wise selection starts at the cursor's column, so the first of four copied lines was empty (`\n112\n113\n114`). `Key::LineStart => (0,y)`
and `Key::Copy` without a mark select `(0,y)..(cols-1,y)`, and the copied line lost its first character (`ash-5.3$ F`, `00` for `200`).
The badge text is "COPY · arrows or hjkl move · v selects · y copies the line · Esc leaves"; the row says **COPY MODE**.

**Bug 3 — prompt jump does nothing in pwsh** (row 2.27).
After `dir` ×5 the view stays at the bottom for `Ctrl+Shift+Up` ×3 / `Down` ×2 (screens `pj-up*`, `pj-dn*`, `hk-up*`, `hk-dn*`, `hk-try.png`).
OSC 133 `A`/`D` are in the PTY log with the hook. In bash with the same keys it works, so it is the pwsh output (probably where the `A`
mark's link lands when the prompt starts with a newline, as Starship's does) and not the key path.

**Bug 4 — bash's OSC 7 path is not a Windows path** (row 2.28).
Git bash's `$PWD` is `/c/dev/tsumugi-armtest/crates`; the hook sends `file://HOST/c/dev/…`, and the pane's folder became
`\c\dev\tsumugi-armtest\crates` (sidebar, status bar, `ls --json` `cwd`).

## Kit notes

- Under JIS the kit's `Ctrl+=` becomes `Ctrl+Shift+Minus`; the bigger-font chord needs `[TsumugiKit.Native]::Chord([uint16[]]@(0x11,0x10),0xBB)`.
- `Send-Text` makes text events only; copy-mode and other key actions need `Send-Keys`.
- `Save-Shot -Crop` takes original-resolution pixels.
- The `.txt` Ctrl+click opens the OpenWith dialog on this machine (killed it).
- `make-testcheck -- --check` and `make-keycheck -- --check` print nothing on success here (exit 0); no `in sync` line.
- A "Welcome back" modal swallows keys after a restart; the sidebar click zone is x < 300.
