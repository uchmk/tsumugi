## Findings

- Not a defect, but it surprised the run: closing the **last** session closes the window and, about 3 s later, the server
  stops (confirmed twice; `server.rs` says it stops when the last session ends). The next start then shows the
  **Welcome back** dialog, and that dialog takes the keys, so text typed before looking went into it.
- `tsumugi new DIR -- C:\Program Files\...\bash.exe …` cannot work: the words are typed into pwsh as a line, so a path with
  spaces is parsed as an expression (`ParserError`). A wrapper `.cmd` avoids it. A `tsumugi new` with an argv, or quoting,
  would help scripts.
- Sending `Ctrl+Shift+End` then `Shift+End` to a bash pane left `FF` typed at the prompt (my own keys; not investigated).
- A Notepad window (`Untitled - Notepad`, not started by this run) took the foreground once; the kit refused to send
  until `Set-Foreground`.
