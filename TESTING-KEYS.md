# Key checklist

Generated by `cargo run -p tsumugi --example make-keycheck` from `crates/tsumugi/src/keys.rs` and the
example's own lists. Ticks are kept across regenerations; anything else here is overwritten. How many are
ticked is not written here (two pull requests ticking keys would collide): `-- --stats`.

A key is ticked when it did what the line says **and nothing else**: the shell did not also get it (no
stray character, no `^[` sequence), no other window opened, the pane with the keys is the same one.
Windows and Linux keys first; the macOS key is after `·`.

- [ ] `Ctrl+Shift+T` · `Cmd+T` — New session · `new_tab`
- [ ] `Ctrl+Shift+W` · `Cmd+W` — Close the session · `close_tab`
- [ ] `Ctrl+Tab` · `Ctrl+Tab` — Next tab · `next_tab`
- [ ] `Ctrl+Shift+Tab` · `Ctrl+Shift+Tab` — Previous tab · `prev_tab`
- [ ] `Ctrl+Shift+U` · `Cmd+Shift+U` — Go to the session waiting longest · `next_waiting`
- [ ] `Alt+Shift+=` · `Cmd+D` — Split right · `split_right`
- [ ] `Alt+Shift+-` · `Cmd+Shift+D` — Split down · `split_down`

- [ ] `Ctrl+,` · `Cmd+,` — Settings · `settings`

## The window, fixed

- [ ] `Alt+Right` · `Cmd+Option+Right` — The keys to the pane on the right
- [ ] `Alt+Up` · `Cmd+Option+Up` — The keys to the pane above

## The new-session dialog

- [ ] `Enter` · `Enter` — Create in a new tab
- [ ] `Alt+Enter` · `Option+Enter` — Create split to the right of the pane with the keys
- [ ] `Tab` · `Tab` — Complete the folder from the list
- [ ] `Up / Down` · `Up / Down` — Walk the folder list

## The input box

- [ ] `Ctrl+Enter` · `Cmd+Enter` — Send the prompt
- [ ] `Ctrl+Shift+Enter` · `Cmd+Shift+Enter` — Queue the prompt for when the session is done
- [ ] `Enter` · `Enter` — A new line, not sent
- [ ] `Up / Down` · `Up / Down` — The prompts sent before (in an empty box, or one showing a sent one)
- [ ] `Esc` · `Esc` — Close the box, the keys back to the pane, the draft kept

## The search box

- [ ] `Up / Down` · `Up / Down` — Walk the entries
- [ ] `Enter` · `Enter` — Do the entry picked
- [ ] `Esc` · `Esc` — Close it

## The settings screen

- [ ] `Esc` · `Esc` — Close it, or leave a key being changed as it was
- [ ] `Ctrl+,` · `Cmd+,` — Open it (the changeable key above, while not moved)
