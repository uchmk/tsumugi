# README の画像の置き場

README の冒頭に載せるキャプチャーの置き場。持ち主が Windows で撮って、ここに次の名前で置く
（GitHub の画面なら、このフォルダで **Add file → Upload files**）。置いたら、対話のセッションが README に載せる。

| ファイル | 何を写すか | 目安 |
| --- | --- | --- |
| `split.png` | 窓の全体。ペインを分けた画面（例: 左に 1 つ、右を上下と左右に分けて 4 つ）。サイドバーのカードと、輪と状態の言葉（`Done · 10s` など）が見えるところ | 幅 1400〜2000 px、PNG |
| `claude.png` | Claude Code を 2 本以上並べて動かしている画面。ペインの見出しとカードが `Running` の輪（シアン）になっているところ | 幅 1400〜2000 px、PNG |
| `demo.gif` | 動き。セッションを足す・分ける・切り替える、待ちになったカードへ `Ctrl+Shift+U` で飛ぶ、など | 10〜20 秒、幅 1200 px 前後、10 MB 以下（ScreenToGif など） |

撮るときの注意:

- 写るパスやブランチ名、Claude Code の会話に、外に出したくないもの（社内の名前、トークン、メールアドレス）が無いかを見る。
- 窓の影や背景の壁紙は入れない（窓だけを撮る。Windows なら `Alt+PrtSc` か、Snipping Tool の「ウィンドウ」）。
- 紹介画像（GitHub の Social preview）は別で、`docs/social-preview.png`（元は `docs/banner.html`）。
